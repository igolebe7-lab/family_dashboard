# FamilyTime — комплект иконок

Создано 8 октября 2026 встроенным ImageGen. Исходник `master.png` содержит настоящий alpha-канал. Текущий промпт сохранён в `prompt-v2.txt`; `prompt.txt` и `previous-calendar-master.png` относятся к предыдущему варианту.

- `transparent/`: прозрачные PNG 16, 20, 24, 29, 32, 40, 48, 57, 58, 60, 64, 72, 76, 80, 87, 96, 114, 120, 128, 144, 152, 167, 180, 192, 256, 384, 512 и 1024 px.
- `install/`: Apple touch 120/152/167/180 px; Android maskable 192/512 px. Эти служебные версии имеют непрозрачную подложку #fffaf3 для системной обрезки. В maskable весь знак помещён в центральный безопасный круг диаметром 80%.
- `favicon.ico`: 16/32/48 px.

В приложение подключены PNG 192/512, maskable 192/512, Apple 120/152/167/180, favicon ICO и PNG 32. Адреса иконок в HTML и manifest версионированы для обновления кеша; идентификатор PWA сохранён. Старый SVG сохранён, но исключён из manifest и HTML. Уведомления используют обновлённый icon-192.png по прежнему пути. Остальные экспортные размеры и исходник находятся вне static, чтобы не раздувать offline-кэш.

Экспорт: `SHARP_MODULE=/absolute/path/to/sharp node scripts/export-app-icons.mjs`. Sharp нужен только для экспорта, зависимостей приложения не добавлено.

Это комплект для существующей PWA, не нативный Xcode Asset Catalog. Прозрачность значка на домашнем экране зависит от ОС. Для уже установленной PWA ОС может сохранить старую иконку; после публикации новой сборки может понадобиться удалить ярлык и добавить приложение на экран Домой заново.

Документация: https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/How_to/Define_app_icons
