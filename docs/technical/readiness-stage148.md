## 14.8.4: HTTPS и контроль ошибок

- Сертификат соответствует IP, действителен до 2026-09-21 04:37:29 UTC.
- Certbot timer: 00:15, 08:15, 16:15 по времени сервера, случайная задержка до
  30 минут; Persistent=true. Последние штатные запуски успешны.
- Backup timer: 04:20, задержка до 15 минут; Persistent=true.
- Реальный `certbot renew --dry-run --cert-name 147.45.136.245` прошёл в
  ограниченной transient-службе (192 MiB / 25% CPU).
- Первая попытка получила HTTP 503 от ACME staging, Retry-After=5,
  `Service busy; retry later`; один повтор после паузы завершился успешно.
- Production-сертификат не заменялся. Dry-run не выполнял deploy hook;
  естественное продление и последующий reload этим тестом не подтверждаются.
- Deploy hook проверен на синтаксис: он проверяет IP/срок и переключает
  сертификат через symlink с reload только Caddy.
- Ошибки доступны через systemd/journal, но OnFailure и внешнее оповещение
  для сертификата и backup отсутствуют. Это незакрытый эксплуатационный риск.
