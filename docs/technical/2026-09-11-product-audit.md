# Аудит и предрелизная доработка FamilyTime

## Область релиза

Приложение остаётся статической SvelteKit PWA с PocketBase/SQLite. Production
Node runtime, новые backend-сервисы и тяжёлые frontend-зависимости не добавлены.
Развёртывание отложено до отдельного выбора площадки; VPN-сервер не изменялся.

Исправлены гонки bootstrap/auth/logout, изоляция активного семейного контекста,
защита `/child`, устаревшие ответы при переключении контекста, demo fallback,
диапазонная загрузка и пагинация. Добавлены поиск, подробности и редактирование,
управление участниками, рабочие списки дел/поручений, реальные inbox и activity.
Модалки используют native dialog, восстанавливают focus и сохраняют scoped drafts.

## Периодические записи

- График работы, секции и занятия создаются как события, без выполнения/approval.
- Дела и поручения создают отдельные выполняемые экземпляры.
- Повторы: ежедневно, по будням, выбранные дни недели, ежемесячно; интервал 1–52
  и необязательная конечная дата.
- Время сохраняется в IANA timezone семьи, а не браузера. Переход DST проверен.
- Отдельное событие можно перенести, не меняя остальные даты серии.
- Архив останавливает показ и генерацию серии, не удаляет историю.
- Расписание рассчитывается RRule 2.8.1 на backend; источник и лицензия в vendor.
- Начальный/ночной горизонт 60 дней, остальные даты создаются по range-запросу.

## Проверка и безопасность

Изолированные backend-тесты используют копии hooks и временные БД, никогда
не очищают рабочую `pb_data`. Автомиграция схемы из тестов отключена.
Проверены private/adults/assignees, смена роли/семьи/managed_by, фальсификация
actor/occurrence/notification, rollback при ошибке записи, child Done и parent
Done с отдельным approval. До миграции локальной рабочей базы сделана копия.

Команды повторной проверки:

```bash
npx pnpm@10.12.1 check
npx pnpm@10.12.1 lint
npx pnpm@10.12.1 test
npx pnpm@10.12.1 build
node scripts/smoke-backend-isolated.mjs smoke-recurrence.mjs smoke-backend-security.mjs smoke-pocketbase-stage4.mjs smoke-auth-profile-flow.mjs
node scripts/smoke-reminders-isolated.mjs
node --test scripts/smoke-cleanup.test.mjs
```

Браузерный release walkthrough проверяет реальные API, поиск/редактирование,
черновик, навигацию и отсутствие горизонтального overflow на 390, 768, 1024,
1280 и 1440 px. Production отдельно проверяется с новым browser context и SW.

## Результаты локальной проверки 2026-09-11

- check и lint: 0 ошибок, 0 предупреждений; static build прошёл.
- Unit: 200 тестов в 40 файлах; cleanup: 4 теста.
- Напоминания: сроки, права получателей, pagination, dedup, rollback/retry и
  фактический минутный cron прошли на изолированной базе.
- Изолированный backend: 7 групп recurrence, 61 security, 13 Stage 4 сценариев,
  регистрация, профиль и запрос восстановления пароля прошли.
- Production browser smoke: все основные экраны, пять ширин окна, scoped drafts,
  создание ребёнка без смены родителя, offline shell без кэширования API прошли.
- Реальный UI расписания: Mon/Wed, 6 экземпляров, браузер Tokyo/семья Amsterdam,
  перенос одного занятия с сохранением после refresh, архив и восстановление прошли.
- Исправлена потеря открытого composer при переключении desktop/mobile breakpoint:
  Today и Calendar теперь используют по одному dialog вне адаптивных оболочек.
- Проверки выполнены автоматизацией Chromium, не заменяют приёмку на физических
  телефонах и проверку production-окружения после выбора хостинга.
- Три семьи текущего UI-прогона и их связанные записи удалены по точным ID;
  отсутствие оставшихся записей проверено. Остальные данные не очищались.

## Оставшиеся ограничения

- Напоминания только в inbox. Web Push и SMTP требуют отдельной настройки;
  HTTP 204 на reset request сам по себе не подтверждает доставку письма.
- Offline: доступна оболочка и сообщение о сети, но не чтение всей семейной БД
  и не очередь изменений. API-ответы не кэшируются service worker.
- Изменение правила всей существующей серии и «с этой даты и дальше» пока
  выполняется заменой серии: архив старой, создание новой. История сохраняется.
- Чеклист отображается, но отдельные отметки его пунктов ещё не редактируются.
- Нет импорта/экспорта ICS, синхронизации Google/Apple Calendar и вложений в UI.
- Дата рождения профиля ещё не автоматически синхронизируется в day_annotations.
- Deployment smoke, HTTPS, внешний backup/restore и реальная доставка писем
  проверяются только после выбора окружения.
