## Исправления, найденные при размещении

1. macOS metadata в tar превращались на Linux в `._*.js`, ломая запуск миграций.
   Упаковщик отключает xattrs/AppleDouble; исправленный архив проверен на Linux.
2. ISO timestamps с `T` и offset в PocketBase filter сравнивались со строковыми
   UTC датами SQLite некорректно: выпадал первый день, нарушались границы сводки.
   Добавлена единая нормализация дат для range, attention, schedule и read snapshot.
   Регрессионные тесты и повторный live UI smoke подтвердили сегодняшние записи.
