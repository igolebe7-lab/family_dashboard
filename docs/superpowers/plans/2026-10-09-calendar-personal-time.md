# Calendar Markers and Personal Time Implementation Plan

**Goal:** Цветные точки записей, единый мобильный месяц, персональный часовой пояс и приветствие.

**Architecture:** Общее отображение точек для двух календарей. Настройка IANA timezone в auth user; UTC timestamps и timezone существующих серий неизменны. Все временные представления получают timezone аккаунта. Дни рождения и особые даты остаются календарными датами.

**Tech Stack:** Svelte, TypeScript, PocketBase/SQLite, Intl, существующее преобразование локального времени.

## Tasks
- [x] Тесты и реализация точек: одна на запись, цвета ответственных/участников, максимум три, при переполнении две и +N. Только видимые записи; не использовать visible_to как принадлежность.
- [x] Общая геометрия мобильного месяца, подсветка текущего дня и доступные подсказки; desktop month сохраняет расширенный вид.
- [x] Timezone аккаунта: Москва по умолчанию, серверная проверка и сохранение, независимость пользователей. UTC-загрузка диапазонов, группировка, формы, сводки и время записей согласованы.
- [x] Приветствие 06–12/12–18/18–23/23–06, обновление по границе и после возврата во вкладку без API polling.
- [x] Unit/backend/UI проверки: 293 unit tests, backend security/flows/series/birthdays/timezones и Go tests. Chrome/WebKit: 320/390/820/1440px, обе темы, сохранение timezone, UTC midnight, модалка и достижимость последнего ряда. Дополнительная Chrome-проверка all-day Kiritimati → Honolulu: дата и запись доступны в Today и подсказке Calendar.

## Publication Procedure
Защищённый PR с полной CI-проверкой, затем штатный versioned release: backup,
миграция на копии базы, atomic deploy и health-check. Факт публикации и SHA
подтверждаются итоговым отчётом после проверки production; VPN-конфигурация
и пользовательские записи не изменяются.

## Review Focus
- Переход UTC суток, DST, события на весь день и дни рождения без сдвига даты.
- Смена пользователя/профиля не смешивает timezone или права.
- Длинные имена, несколько участников и переполнение точек на 320px.
- Повторяющиеся серии сохраняют исходную timezone и дни недели при редактировании.
