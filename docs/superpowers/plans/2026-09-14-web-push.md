# Stage 14.1-14.4: PWA и Web Push

**Goal:** локально подготовить PWA с системными уведомлениями и комплект размещения по IP.

**Architecture:** согласована собственная сборка PocketBase 0.38.2 с Go-расширением и webpush-go. Существующие JS hooks и миграции остаются. Доставки хранятся в SQLite, без внешнего брокера и Node runtime. Никаких подключений или изменений VPS на этом этапе.

## Контракты и безопасность

- Подписки принадлежат auth users, не переключаемому UI-профилю. Managed child без аккаунта не получает отдельную подписку.
- `GET /api/familytime/push/config` сообщает публичный VAPID key и готовность.
- Authenticated `PUT /api/familytime/push/subscription` регистрирует устройство; browser-generated secret запрещает захват чужого endpoint.
- `POST /api/familytime/push/revoke` отзывает устройство по секрету даже после истечения auth.
- `POST /api/familytime/push/test` проверяет отправку только на своё устройство.
- Endpoint: только HTTPS известных browser push providers, без redirects и private addresses.
- Перед каждой отправкой: действующий user token key, срок сессии, членство и актуальное read rule notifications.
- На lock screen только нейтральный текст; подробности требуют входа. Уникальная пара notification/subscription и стабильный tag уменьшают дубли; exactly-once через внешнюю сеть не обещаем.
- Logout очищает локальное разрешение отображения в worker, отписывает браузер и отзывает серверную запись. Offline revoke повторяется при восстановлении сети.

## Результаты локальной проверки, 2026-09-14

- `pnpm check` и `pnpm lint`: 0 ошибок и предупреждений; `pnpm test`: 219 тестов, 47 файлов.
- Go tests с race detector: passed. PocketBase 0.38.2 собирается с `GOEXPERIMENT=nojsonv2`: JSONv2 Go 1.27 вызывает рекурсию в upstream Collection.UnmarshalJSON; добавлена compile-time защита от несовместимой сборки.
- Изолированный backend smoke: 62 security-проверки и 13 flow-проверок; reminders smoke: 5 групп, включая cron и дедупликацию. Пользовательская база не затронута.
- Production service worker в Chrome: синтетический push отображается, небезопасная ссылка заменяется inbox, logout закрывает уведомления и блокирует последующие push. Desktop 1440x900 и mobile 390x844 без горизонтального переполнения; iPhone installation gate проверен эмуляцией UA, не настоящим Safari.
- Caddy: локальная TLS-проверка сертификата с IP SAN без SNI; запрещены административные коллекции по имени и ID; проксируются API приложения и отдельные `/familytime/invitations/*` маршруты.
- ShellCheck: backup/restore/certificate scripts passed. Выполнение systemd, реальное восстановление серверной базы и выпуск публичного сертификата остаются серверными проверками.
- Linux amd64 release включает static frontend, backend, hooks, migrations, deployment files и SHA256SUMS; не включает пользовательскую базу или реальные VAPID secrets.
